### 🛠️ Featured projects

**[Poulinage](https://github.com/thibaultfradet/poulinage)** · Kotlin, Jetpack Compose · *in production*
A foaling alarm for horse breeders. A phone strapped to the mare reads the accelerometer, detects when she lies down to give birth, and sends SMS and email alerts. It was built natively in Kotlin so it runs on the old Android phones the client already had, and it keeps logs queued while offline.

**[Mini Jira](https://github.com/thibaultfradet/jira-mini-front)** · React, TypeScript, REST API ([back end](https://github.com/thibaultfradet/jira-mini-back))
A Jira-style project manager with a Kanban board, backlog, sprint planning, and user administration.

**[Nuage](https://github.com/thibaultfradet/cloud)** · Symfony 8, Stimulus, Turbo, Tailwind
A self-hosted personal cloud: nested folders, color-coded tags, full-text search, inline previews, and bulk ZIP downloads.

**[Terminaly](https://github.com/thibaultfradet/Terminaly)** · Symfony
An ordering kiosk for fast-food vendors: real-time cart, multiple payment methods, role-based access, and sales analytics.

**[Claude Kanban](https://github.com/thibaultfradet/claude-kanban)** · Python, FastAPI
A local Kanban board that hands tickets to AI coding agents, with a human reviewing every change before it's committed.
